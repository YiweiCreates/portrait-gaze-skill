## Demonstration artwork

`examples/portrait-blank.png` is a newly AI-generated fictional adult character, created on 2026-10-13 using the host's OpenAI image-generation tool. The tool did not report a specific model version. The character is not intended to depict a real person. The image has been re-encoded to remove embedded metadata.

Prompt summary: front-facing fictional adult female explorer, short dark hair, ochre skin, teal jacket, pale sage background, editorial storybook illustration with no named-artist style; fully empty ivory eye whites enclosed by dark eyelids; no text or watermark.

`outline-check.png`, `demo-preview.png`, `eyes.json` and `portrait-gaze-demo.html` are generated from that artwork and this repository's code. The iris color and size are design choices, not measured biographical facts.
